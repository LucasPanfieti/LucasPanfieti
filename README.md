## 👨‍💻 Sobre mim

Olá! 👋 Sou **Lucas Panfieti**, desenvolvedor de software com formação em **Análise e Desenvolvimento de Sistemas** pela Anhanguera.

Atuo com foco em **front-end**, construindo interfaces modernas, rápidas e bem estruturadas usando **React**, **Next.js**, **TypeScript** e **Tailwind CSS**. Tenho experiência prática com integração de APIs, autenticação de usuários e gerenciamento de estado no cliente (incluindo soluções como **Supabase** e **LocalStorage**).

Também sou o criador do [**LampStore**](https://www.lampstore.com.br/), uma plataforma SaaS de e-commerce com dashboard, analytics e vendas integradas via WhatsApp — um projeto real que reforça minha preocupação com produto, performance e experiência do usuário.

Sigo evoluindo constantemente dentro do ecossistema JavaScript, buscando não só escrever código funcional, mas construir produtos que realmente fazem sentido para quem usa.

**⚡ Highlights:**
- 🏗️ Arquitetura de componentes escalável e foco em performance
- 🎨 Design funcional com atenção real à experiência do usuário (UI/UX)
- 📦 Deploy e distribuição com Vercel e GitHub Pages
- 🔄 Versionamento e colaboração com Git e GitHub
- 📍 São Paulo, Brasil
